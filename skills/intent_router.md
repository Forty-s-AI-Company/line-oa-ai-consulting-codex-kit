# intent_router

## 目的
分類使用者意圖、辨識是否需要補問與風險升級。

## 輸入
- user message
- recent conversation
- session tags

## 輸出
- primary_intent
- secondary_intents
- confidence
- missing_fields
- risk_hints

## 類別
- nutrition_consulting
- beauty_consulting
- cleaning_consulting
- water_consulting
- air_consulting
- business_consulting
- customer_service
- onboarding
- small_talk
- unknown
